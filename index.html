Repository format ▸

repository.json is a JSON array of payload objects. Fields marked ● are required.

[
  {
    "name":        "websrv",              // ● display name
    "filename":    "websrv_v0.32.elf",    // ● saved filename (.elf / .bin)
    "url":         "https://.../file.elf",// ● direct download link
    "version":     "v0.32",               // version string
    "description": "A simple web server…", // short description
    "last_update": "2026-05-25",            // YYYY-MM-DD
    "checksum":    "8dd24df1…",            // sha-256 of the file
    "source":      "https://github.com/…", // project releases page (optional)
    "extract_file":"payload.elf"           // file to pull from a .zip (optional)
  }
]

Edit repository.json at the root of this repo, commit, and the changes go live automatically. See the PS5 Payload Manager Custom Repositories Guide for full details.
